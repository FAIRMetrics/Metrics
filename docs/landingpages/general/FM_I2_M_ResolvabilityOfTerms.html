FAIR Metric – I2 – Metadata - Resolvability of metadata terms

This metric evaluates whether the property terms (predicates or keys) used within the metadata record under evaluation are themselves resolvable.

Implementations should inspect the structure or context of the metadata (such as a JSON-LD @context mapping or XML namespace declaration) to construct full URIs for the property terms. For example, if a record declares a @context of http://schema.org/ and uses the property term inLanguage, implementations should construct the URI http://schema.org/inLanguage and attempt to resolve it over HTTP(S).

As a minimal implementation of Principle I2, a metadata record should receive a pass from test implementations of this metric if at least one property term URI can be constructed and resolves successfully. It receives a fail result if property term URIs can be constructed from the record but none of them resolve. If no URIs can be constructed from the property terms within the metadata record, the result is indeterminate.

Why should we measure it?

FAIR Principle I2 requires that metadata use vocabularies that follow FAIR principles, ensuring that descriptive terms can be unambiguously interpreted across systems. Verifying that metadata property terms resolve to active definitions allows automated tools to look up the underlying schema rules, preventing semantic misinterpretations and supporting consistent processing across the research community.
